Migration X-RaySAGE 50 → ERPNEXT · 100% CLIENT-SIDE

Everything else on this site is quality assurance over data you can still retrieve. This page is the part that stops being possible. When the Sage licence ends the software can go read-only or stop opening altogether, and a ledger you cannot open is a ledger you cannot export. Run these while it is live — before deciding anything about the migration, and regardless of which way that decision goes.

Licence deadline

Kept in this browser only, alongside the ticks below. Confirm the date against the contract rather than the renewal email — and confirm whether it expires or auto-renews, because the notice deadline for cancelling usually falls well before the end date.

The runbook

Check the archive

Drop the whole folder of exported CSVs here. Each file is matched to its slot in the runbook and checked for the things that make an export useless later: no data, a reduced field list, a header row left off, rows that do not line up, and — for the audit trail — how much of the history it actually covers. Nothing is uploaded and nothing is kept.

The manifest records filenames, row and column counts, date ranges and checksums — metadata about the archive, never a value out of the ledger. File contents stay in this tab and are dropped when you clear or close it.

Each file is auto-detected, profiled for defects, and converted into ERPNext-ready import CSVs. Column layouts target the ERPNext v15 Data Import templates and should be verified against your live instance during Phase 0 — every generated file says what it maps to.

Privacy by design: no network requests, no storage — conversion happens in this browser tab and downloads go straight to your machine. Safe for live client data.

Parallel-run assurance. Paste the same period from both systems — either trial balances (account, debit/credit or balance) or transaction lists (date, ref, amount). The engine matches account codes and references, and reports every difference: balance deltas, accounts on one side only, transactions missing or mutated. Run it weekly during the parallel run; the accountant signs off a clean report before cutover.
