Exploded structure

Every top-level assembly, expanded through its sub-assemblies. Quantities are per one unit of the parent; the rolled-up cost is computed from component costs upward. Click a code to see where it is used.

Where used

Every parent that consumes the selected component, at any level. Use this before changing or discontinuing a part.

Load a bill of materials

Expects one row per BOM line — a parent assembly, the component it consumes, and the quantity. Columns are matched fuzzily, so Sage Manufacturing, ERPNext and spreadsheet layouts all work. Optional columns (cost, unit of measure, status, parent cost) unlock the costing and lifecycle checks.
